AKTIEVÆRKTØJ – INSTALLATION

Upload alle filer i denne mappe samlet til samme HTTPS-mappe:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Nyheder i version 7:
- Aktiesalg og skat er igen samlet i ét enkelt års-overblik.
- ASK-handler står i samme salgsliste, men er diskret markeret med gylden kant og ASK-badge.
- ASK-skatten beregnes fortsat separat og vises kompakt i den normale skatteboks.
- Depot vælges direkte i Tilføj/Rediger salg.
- Baggrundens scrolling er låst i alle menuer og dialogvinduer.
- Scrollpositionen gendannes, når menuen lukkes.

Ved opdatering kan browseren kortvarigt vise den gamle version. Genindlæs siden,
eller luk og åbn den installerede app igen. Service-workerens cache er ændret til v7.

Version 8: Mere diskret ASK-design, enklere salgsformular og depotfilter/sortering.
